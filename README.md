# Вики SugarLife

Объяснения для людей, пользующихся приложением: почему оно ведёт себя так и чем платят настройки. Публикуется через GitHub Pages на свой домен; приложение ссылается сюда полем `helpUrl` у параметров и настроек (SugarLifeCore#16).

## Устройство

- `index.md` — список статей;
- `help/*.md` — сами статьи, по одной на вопрос;
- адреса латиницей (`/help/calibration`), заголовки и текст по-русски: адрес попадает в код и в ссылки, и кириллица там превращается в проценты.

## Правило

Статья пишется ДО того, как в приложении появляется настройка. Сначала формулируем, что скажем человеку, и только потом делаем переключатель — иначе получается галочка «Advanced auto-calibration (Recommended)», которую никто не может объяснить.
